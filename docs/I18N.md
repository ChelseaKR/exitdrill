# Internationalization

i18n status: N/A

Reason: ExitDrill is a single-operator, English-only command-line tool for
technical drill operators. It has no hosted or public-facing service and no
civic or bilingual delivery obligation. The offline HTML report is operator
evidence rendered from a verified receipt, not a public interface.

This declaration flips to Applies if the project adds a public-facing surface,
a hosted service, or a delivery commitment to a bilingual audience. From that
point the portfolio internationalization standard's catalog, parity, and
review gates apply to the first user-visible string onward.
